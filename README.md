# 📸 摄影简介

## 什么是摄影？

摄影（Photography）是一种利用相机及光学设备，通过捕捉光线在感光介质（如数码传感器或胶片）上形成影像的艺术与技术。  
它既是一种记录现实的方式，也是一种表达情绪、思想和审美的语言。

---

## 摄影的核心要素

### 🌞 1. 光线（Light）
光是摄影的基础。  
- 光的强弱、方向、颜色都会影响照片的视觉效果。  
- 优秀的摄影师善于观察和利用自然光与人造光。

### 📷 2. 构图（Composition）
构图是画面布局和视觉引导的艺术。  
常见构图方法包括：
- 三分法（Rule of Thirds）
- 对称与平衡
- 线条引导
- 层次与前景元素

### 🎛 曝光（Exposure）
曝光指感光元件接收光线的量，它由三个参数共同决定：
- 光圈（Aperture）
- 快门速度（Shutter Speed）
- 感光度 ISO

良好的曝光可以表现丰富细节、适当亮度与氛围。

### 📍 4. 对焦（Focus）
对焦决定主体是否清晰，常用自动对焦（AF）或手动对焦（MF）。  
对焦准确会让主体更突出，模糊背景则能营造空间感。

## 常见摄影类型

| 类型 | 描述 |
|------|------|
| 📷 风光摄影 | 拍摄自然景色、山川河海、天空云层 |
| 🏙 城市摄影 | 记录城市建筑、街道氛围与人文瞬间 |
| 👤 人像摄影 | 强调人物表情、情绪与故事 |
| ✨ 宏观摄影 | 拍摄微小物体，如昆虫、花朵等 |
| 📑 纪实摄影 | 记录现实事件，具有社会意义 |
| 🎞 夜景/星空 | 低光环境下的长曝光艺术 |

---

## 初学摄影常用术语

- **RAW / JPEG**：照片文件格式  
- **大光圈**：更浅景深，更强背景虚化  
- **连拍**：快速连续拍摄多张照片  
- **白平衡（WB）**：控制色温，避免偏色  
- **构图线条**：通过线条引导观众视线

## 摄影的意义

摄影不仅记录现实，更是一种表达方式。  
它可以：
- 定格时间与记忆  
- 传递情绪与故事  
- 展现世界独特视角  
- 激发想象与思考

## 📌 总结

摄影是一门光与影的艺术，是**技术与审美结合的创作方式**。  
只要带着好奇心和观察力，每个人都可以用镜头“看见”属于自己的世界。
